# 深夜喫茶 境界

> 同じリポジトリに、カードゲームの試作 [カミアソビ](kamiasobi/) と [サキュバスシスターズ](succubus-sisters/) もあります。

雨の夜にだけ開く喫茶店で、幻想郷の客に一杯を淹れるブラウザゲームです。
東方Projectの二次創作で、Coffee Talk に着想を得た非公式ファンゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールは要りません。

- 材料を三つ選んで一杯を淹れます。一つ目は必ずベース（コーヒー・紅茶・緑茶・ココア）です。
- 注文は「甘くてあたたかいの」のように気分で届くことがあります。調合中の「温・甘・苦・爽」の目盛りを手がかりにしてください。
- 全三夜。出した一杯と会話の選択で、その後の台詞や結末が変わります。
- 見つけたレシピと常連の記録は「手帳」で確認できます。進行は夜のはじめにブラウザへ自動で記録されます。

## 収録内容

- 登場人物：博麗霊夢・霧雨魔理沙・魂魄妖夢・十六夜咲夜・八雲紫
- レシピ：18種（うち一つは作中で名前が変わります）
- エンディング：2種

## 構成

ゲームは `index.html` 一枚にまとまっています。台詞は `NIGHTS`、レシピは `RECIPES`、材料は `ING` の配列を書き換えれば追加・修正できます。

画面は高さ216ドットで描いて拡大表示するドット絵です。店内・雨の窓・立ち絵・材料アイコンはすべてコードで描いており、公式や他作品の画像素材は使っていません。立ち絵は `charLayers`（輪郭と服）と `EYE`・`BROW`・`MOUTH`（1ドットずつ打った表情パーツ）で定義しています。塗りは黒い輪郭線を使わず、紫寄りの影・中間色・淡いハイライトの3段で、重なった部分には影を落とします（`paint`）。

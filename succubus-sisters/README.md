# サキュバスシスターズ（デジタル試作）

「260717_基本ルール」と、GFカードシート【印刷】260714 _120枚Ver のカードで遊べるブラウザ版です。
`index.html` をブラウザで開くだけで動きます。あなた＋CPU（合計4〜8人）で3戦して勝利点を競います。

## 実装したもの

- 神託：サキュバス1・堕天使（5〜6人で1、7〜8人で2）・シスター
- ターン：ドロー（6枚まで補充、引けなければ終了）→ オラクル（顕現・告解・供与、2巡目から）→ アタック
- 1巡目は ♥カード・†カード・オラクルが使えない
- 攻撃：単体／全体／ランダム（全員が山札をめくってトリガー判定）、《追撃》チェイン（属性は最初、範囲は最後のカード）
- 防御：複数枚、属性一致ルール、《反射》《全反射》《無効》《除去》《反撃》、ドレイン系の盾
- ☆魔法：HPを払って使い、場に残る（場からまた使える）。夜魔のホウキで破棄できる
- †カード（断罪）：成功・失敗の処理、断罪成功の勝利点
- ♥カード：シスター・堕天使は上の面、サキュバスは下の面。使うと正体が明かされる。「立場をわからせる」で封印
- 顕現：HPを30に戻す（断罪で制限あり）、手札上限＋1、《吸収》、手札補充、キャラ固有のサキュバス能力（13人分）
- 特殊カード：昇天弓、太陽のお守り、ドキドキなみだ、誓いの祈り、寄進の行い、許しの告解、秘密の懺悔、じゃしんのつるぎ ほか
- 勝利点：4通りの終了条件ごとの計算、3戦の合計

## 画像

`img/` にGoogleドライブ「GFカード / JPEG」の画像を、Web用に縮めて入れています。

- `img/chara/<キャラ>_hito.jpg`・`<キャラ>_oni.jpg`：キャラクターカード（シスター面・サキュバス面）。キャラ選択画面、顕現の演出、神託の画面で使う
- `img/face/`：上のカードから顔のまわりを切り出したもの。プレイヤーのアイコンに使う（顕現するとサキュバス面に切り替わる）
- `img/cards/001.jpg`〜`120.jpg`：アイテムカード。番号はシートのIDと同じ。説明欄の「実物カードを見る」で表示する

## カードの差し替え

`index.html` 冒頭の `CARD_TSV` は、シートの A〜V 列（採用〜♥効果）をそのまま貼ったものです。
シートで行を選んでコピーし、この中に貼り替えればカードが更新されます。

- 攻撃・防御・範囲・属性・コスト・トリガーは列から読みます
- 《吸収》《即死》《追撃》《追撃不可》《反射》《全反射》《無効》〔属性〕《除去》《反撃》《活力》、「HPをN回復する」「続けてもう1枚カードを…」「属性を〔X〕に変えてもよい」は効果文から読みます
- それ以外の固有効果はカード名で `SPECIAL` に登録しています。新しい固有カードを足すときはここに追加が必要です

## ルールの解釈（要確認）

文書だけでは決めきれなかったところを、こう決めて作っています。

1. 文書の「天罰／必殺」の名前が途中で入れ替わっているため、シートの記号どおり **†＝シスター専用（断罪）**、**♥＝両面カード** として扱う
2. †カードは「正体を明かしているシスターのみ」だが、使った時点で自動的に正体を明かす
3. ☆魔法は使ったあと場に残り、何度でも使える（夜魔のホウキ・マラリヤの記述から判断）
4. 《反撃》の「受けたダメージ」は、防御したあと実際に受けたダメージ
5. 《反射》《無効》《除去》や「立場をわからせる」は、効果が働く攻撃なら属性に関係なく出せる
6. 《追撃》で重ねた杖の「属性を変えてもよい」は、常に変える
7. 昇天（HP0）はエンドフェイズではなく、その場ですぐ処理する
8. 回復カード（範囲：単体）は自分にもほかの人にも使える
9. 仮ルール：何もしないときはパスでき、その際に手札を1枚捨ててもよい（手札が回らず止まるのを防ぐため）
10. 3人用の特殊ルールは未定のため、4〜8人のみ

## 追加ルール

- 生き残りがサキュバスと堕天使だけになったら、その時点でゲーム終了。サキュバス陣営の勝ち（サキュバスと堕天使に＋3）

## 構成

`index.html` 一枚です。主な関数：

- `buildCardDefs` / `makeFace` / `parseKw`：カードの読み込み
- `takeTurn` / `actionPhase` / `playAction`：ターン進行
- `doAttack` / `strike` / `doJudge`：攻撃・防御・断罪の解決
- `manifest` / `handleConfessions` / `doGift`：顕現・告解・供与
- `finishGame`：勝利点の計算
- `cpuPlan` / `cpuDefend`：CPUの行動と防御

# メスガキ・クー

カードゲーム「クー (Coup)」にメスガキ要素を足したブラウザゲームです。
基本ルールはクーのまま。コインは♥、役職はガキカード、ライフを失うとメスガキカードが裏返ってボロ絵になり、その下に敷いたトリガーカードが発動します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールは要りません。

- 対戦人数は2〜5人（あなた＋CPU）。「おまかせ」にすると自分の手もCPUに任せて観戦できます。
- 画面上の「ルール」ボタンで早見表（アクション・ガキカード・トリガー）が見られます。
- 自分の番は下のパネルから行動を選びます。ほかのプレイヤーの主張には「チャレンジ！」や「は？」ブロックで割り込めます。

## カード

| 種別 | 枚数 | 内容 |
| --- | --- | --- |
| ガキカード | 15 | メスガキ・後輩ガキ・幼馴染ガキ・サキュガキ・わからせおじさん（各3枚） |
| メスガキカード 上/下 | 5組 | 表は普通の服、裏はボロ絵。キャラ5人分 |
| トリガーカード | 10 | 早見表のトリガー効果 |
| ノントリガー（ハズレ） | 5 | 効果なし |

### アクション

| アクション | 条件 | 効果 | 「は？」ブロック | チャレンジ |
| --- | --- | --- | --- | --- |
| ふ～ん♥ | なし | 1♥獲得 | 不可 | 不可 |
| よわ♥ | なし | 2♥獲得 | メスガキ | 不可 |
| ざぁ～こ♥ | 7♥（10♥以上なら必須） | 相手の影響力を1つ失わせる | 不可 | 不可 |
| よわよわ～♥ | メスガキ | 3♥獲得 | 不可 | 可 |
| なさけな～い♥ | 後輩ガキ | 相手から2♥奪う | 後輩ガキ・幼馴染ガキ | 可 |
| ダサすぎ♥ | 幼馴染ガキ | 山札から2枚引き2枚戻す | 不可 | 可 |
| まけちゃえ～♥ | サキュガキ＋3♥ | 相手の影響力を1つ失わせる | わからせおじさん | 可 |

### 影響力を失ったとき

1. 手札（ガキカード）を1枚、自分で選んで捨てる。
2. メスガキカードの上か下を裏返してボロ絵にする。
3. その下に敷いていたトリガーカードを表にして効果を発動する。

両方ボロ絵になったら脱落。最後の1人が勝ち。

## この実装での取り決め

早見表に書かれていない部分は `index.html` 冒頭の `RULES` で切り替えられます。

- `peekOwnTriggers`：自分の下に敷いたトリガーは自分だけ見られる（既定 ON）。
- `win15LiftsForcedCoup`：「♥コレクター」を持つ人は10♥の強制ざぁ～こ♥を免除（既定 ON。免除しないと15♥に届かないため）。
- 「ダサすぎ返し」は公開済みトリガーによるブロックなので、チャレンジできない。
- 「まわして」の右隣は、席順で次のプレイヤー。
- トリガー名は早見表で空欄だったので仮の名前を付けています（`TRIGGERS` を書き換えれば変更できます）。
- わからせおじさんのブロック台詞も空欄だったので「は？負けさせないが？」を仮置きしています。

## 構成

ゲームは `index.html` 一枚です。

- 役職・アクション・トリガー・台詞：`ROLES` / `ACTIONS` / `TRIGGERS`
- キャラ（髪型・服・配色）：`CHARS`
- 立ち絵：`drawFigure` が 32×64 ドットで描き、上半身（0〜33行）と下半身（34〜63行）の2枚に分けます。ボロ絵は同じ絵に破れ・泥・絆創膏・涙を足したものです。
- 進行：`runGame` → `takeTurn` → `performAction`。チャレンジは `challengeWindow`、ブロックは `blockWindow`、影響力の喪失とトリガーは `loseInfluence` / `resolveTrigger`。
- CPU：`cpuChooseAction` ほか `cpu*` 関数。

立ち絵はボンバーガール風の通常絵／ボロ絵を目指して自前のドット絵で描いており、公式画像は使っていません。

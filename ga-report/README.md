# 月次アクセスレポート

Google Analytics 4（GA4）のデータを読み、「次にどんな記事を書くとよいか」のアドバイス付きレポート（HTML）を作るツールです。

レポートには次の内容が入ります。

- 主な数字（読者数、表示回数、検索から来た割合、閲読時間）と前月比
- 次に書く記事のアドバイス（優先度の高い順）
- 記事の種類ごとの成績（1本あたりの読者数と閲読時間）
- 伸びた記事・落ちた記事（前月のデータがあるとき）
- よく読まれた記事、読者がどこから来たか、言語別の内訳

## 毎月の使い方

### 方法 A：GA4 の画面から CSV を書き出す（準備なしで使える）

1. GA4 で期間を「先月」にして、次の 2 つのレポートを CSV で書き出します。
   - 「エンゲージメント → ページとスクリーン」（表の左上を「ページ タイトルとスクリーン クラス」にする）
   - 「集客 → ユーザー獲得」（「ユーザーの最初のメディア」）
2. 月ごとのフォルダに、次の名前で保存します。

   ```
   ga-report/data/2026-09/pages.csv
   ga-report/data/2026-09/acquisition.csv
   ```

3. レポートを作ります。

   ```
   python ga-report/report.py ga-report/data/2026-09
   ```

   `ga-report/reports/2026-09.html` ができるので、ブラウザで開きます。前月のフォルダ（`data/2026-08`）があれば、自動で前月と比べます。

Python 3.9 以上があれば、追加のインストールは要りません。

### 方法 B：GA4 から自動で取得する

1. Google Cloud でサービスアカウントを作り、「Google Analytics Data API」を有効にして、鍵（JSON）をダウンロードします。
2. GA4 の「管理 → プロパティのアクセス管理」で、サービスアカウントのメールアドレスを「閲覧者」として追加します。
3. 準備をします。

   ```
   pip install -r ga-report/requirements.txt
   export GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json
   export GA4_PROPERTY_ID=123456789   # 管理 → プロパティの詳細 にある数字
   ```

4. 先月分を取得して、レポートまで作ります。

   ```
   python ga-report/fetch_ga4.py --report
   ```

   初回は前月分も一緒に取得するので、最初から前月比が出ます。毎月 1 日にこのコマンドを実行するよう、cron や Windows のタスク スケジューラに登録すれば全自動になります。

## 注意：データを公開しない

このリポジトリは公開されています。`data/` と `reports/` は `.gitignore` で除外しているので、コミットされません。GitHub Actions で自動化する場合は、ログや成果物が外から見えないよう、非公開のリポジトリで動かしてください。

## 記事の種類を変える

記事の種類は、タイトルに含まれる言葉で自動で分けています。分け方は `config.json` で変えられます。

- `categories`：種類の名前と、タイトルに含まれる言葉（正規表現）。上から順に当てはめます。
- `evergreen: true`：検索で長く読まれる種類。アドバイスの文面に使います。
- `hub_pattern`：トップページや一覧ページなど、記事として数えないページ。
- `languages`：タイトルの末尾に付くサイト名で言語を判定します。

## アドバイスの決め方

種類ごとの「1本あたりの読者数」「本数」「閲読時間」を、全種類の中央値と比べて判定しています。

| 判定 | 条件 |
|---|---|
| 増やす | 1本あたりの読者数が中央値の 1.3 倍以上で、本数は中央値以下 |
| 続ける（柱） | 記事の読者の 15% 以上を占め、閲読時間も中央値以上 |
| まとめる | 本数が中央値の 1.5 倍以上なのに、1本あたりの読者数は中央値の 0.7 倍以下 |
| 回遊 | 1本あたりの読者数は多いのに、閲読時間が中央値の 0.6 倍以下 |
| 英語版など | 主言語以外で、読者の 40% 以上が 1 本の記事に集中している |
| 伸び・リライト | 前月と比べて、種類や記事の読者が大きく増えた・減った |

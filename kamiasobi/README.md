# カミアソビ

ゴッドフィールドのような、神々が武器・防具・奇跡のカードで戦うバトルロイヤル型カードゲームの試作です。
`index.html` をブラウザで開くだけで遊べます。あなた＋CPU3人の4人戦です。

## ルール

- 自分の番のはじめにカードを1枚引き、行動をひとつ選ぶ：**攻撃**（武器＋紋章）／**奇跡**（MPを払う）／**道具**／**祈る**（2枚引く）
- 攻撃されたら防具を選んで守る。守備力の合計だけダメージが減り、使ったカードはなくなる
- HPが0で脱落。最後に残った者が勝ち
- ときどき旅の商人が現れ、お金でカードを買える

### 属性

防御の相性は「水は火を、火は木を、木は土を、土は水を防ぐ」。無属性の攻撃はどの防具でも防げます。
光の攻撃は光の防具でしか防げず、闇（死神の鎌）は光の防具で防がないと即死します。反射の鏡はどんな攻撃も跳ね返します。

## 構成

`index.html` 一枚に全部入っています。

- `CARDS`：カードの一覧。`w` は出やすさ（重み）。数値を変えればバランス調整できます
- `ROSTER`：参加者。`ai` は CPU の性格（`aggro` 弱った相手を狙う／`balanced`／`careful` 首位を狙い早めに回復）
- `cpuChoose` / `cpuDefend`：CPU の行動と防御
- `resolveAttack` / `computeHit`：攻撃の解決とダメージ計算

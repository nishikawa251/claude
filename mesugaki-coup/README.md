# メスガキ・クー

カードゲーム「クー (Coup)」にメスガキ要素を足したブラウザゲームです。
基本ルールはクーのまま。コインは♥、役職はガキカード、ライフを失うとメスガキカードが裏返ってボロ絵になり、その下に敷いたトリガーカードが発動します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールは要りません。

- 初めてなら開始画面の「チュートリアル」を。台本どおりに進む1戦を遊びながら、ナビが毎手の意味（主張・ブロック・チャレンジ・脱ぐ・トリガー・ざぁ～こ♥）を説明し、押す場所を絞って案内します。
- 対戦人数はクーと同じ3〜6人（あなた＋CPU）。
- トリガーは開始画面で「基本デッキ」「新カードデッキ」「おすすめデッキ」か、全カードから好きな12枚を選ぶ「カスタム」を選べます（選択は保存されます）。「おまかせ」にすると自分の手もCPUに任せて観戦できます。
- 画面上の「ルール」ボタンで早見表（アクション・ガキカード・トリガー）が見られます。
- 自分の番は、アクションのタイル（ガキカードと同じ色・同じ名前の帯）を押すか、手札のカードを直接クリックして行動します。持っていない役職のタイルは破線で「ハッタリ」と表示されます。ほかのプレイヤーの主張には「チャレンジ！」や「は？」ブロックで割り込めます。

### プライドを失ったとき

1. 手札（ガキカード）を1枚、自分で選んで捨てる。
2. 失わせた相手が、メスガキカードの上か下を選んで裏返し、ボロ絵にする。
3. その横に敷いていたトリガーカードを表にして効果を発動する（自分のトリガーは自分だけ見える）。

両方ボロ絵になったら脱落。最後の1人が勝ち。

## この実装での取り決め

早見表に書かれていない部分は `index.html` 冒頭の `RULES` で切り替えられます。

- `peekOwnTriggers`：自分のトリガーを自分だけ見られる（既定 ON）。
- `triggerDeal`：開始時に配るトリガー枚数（既定 2。配られた2枚をそのまま上半身・下半身に仕込むので、ハズレを引いたら仕込むしかない）。3以上にすると2枚を選んで残りを山に戻す。
- デッキのプリセットは `DECK_PRESETS`（basic / fresh / mix）。ゲームに使う12枚は `DECK.ids`。
- `collectorGoal`：♥コレクターの勝利条件（既定 9♥。持っていれば9♥になった時点で勝ち）。公開した瞬間に山分け（自分より♥の多い全員から1♥）も起きる。
- `punishCost`：おしおき返しの即時ざぁ～こ♥のコスト（既定 5♥）。
- `attackerChoosesFlip`：プライドを失わせた側が、相手の上半身・下半身どちらを脱がせるか選ぶ（既定 ON）。
- `dudCount`：ハズレ（効果なし）トリガーの枚数（既定 0）。
- みちづれのキスで見た相手の手札、トリガーチェックで見た相手のトリガーは、見た本人にだけ表示される（CPUも覚えて判断に使う。知っているトリガーがあれば、脱がせるときに自分へ跳ね返りにくい方を選ぶ）。
- 着替え（2軍）はプライドが0になる脱ぎでめくれたときだけ発動する。山札から1枚引いて脱落を免れる（♥は0になる）。服は両方ボロのまま続行し、次にプライドを失うと脱落。
- 全員が同時に脱落したら（おしおき返しの相打ちなど）、最後に脱落した人の勝ち。
- `win15LiftsForcedCoup`：「♥コレクター」を持つ人は10♥の強制ざぁ～こ♥を免除（既定 ON。`collectorGoal` を10♥より上にしたときに効く）。
- ルール改変は持ち主だけに効く。以後その人の「ダサすぎ♥」は、通常（山札から2枚引いて2枚戻す）か審問（相手の手札1枚を見て山札と交換させる。幼馴染ガキでブロック可）かを宣言時に選べる。
- 道連れは、脱がせてきた相手の手札が2枚のときだけ発動する（1枚の相手には不発）。
- 総入れ替えは全員（自分も）が手札を1枚伏せて出し、持ち主だけが全部見て1枚もらう。残りはシャッフルして自分以外に1枚ずつ戻す。
- 公開・交換で手放したガキカードは捨て札に置く。山札が尽きたら捨て札を切り直して山札にする（失ったプライドのカードは戻らない）。
- 「ダサすぎ返し」は公開済みトリガーによるブロックなので、チャレンジできない。
- 「まわして」の右隣は、席順で次のプレイヤー。
- トリガー名は早見表で空欄だったので仮の名前を付けています（`TRIGGERS` を書き換えれば変更できます）。
- わからせおじさんのブロック台詞も空欄だったので「は？負けさせないが？」を仮置きしています。

## 構成

ゲームは `index.html` 一枚です。

- 役職・アクション・トリガー・台詞：`ROLES` / `ACTIONS` / `TRIGGERS`
- キャラ（id と表示名）：`CHARS`
- 立ち絵：`img/{id}_{top|bottom}_{000|001}.webp`（000=通常絵、001=ボロ絵）を上半身・下半身の2枚のカードとして表示します。画像が無いときはキャラ名のプレースホルダーになります。
- 画像の生成：`tools/split_cards.py` が元の立ち絵（通常絵の透過PNGとボロ絵のJPG）を腰の位置で上下に分割し、印刷用PNGとA4両面シートを出力します。ゲーム用の `img/` はその出力を 416×298 の WebP に縮小したものです。
- 進行：`runGame` → `takeTurn` → `performAction`。チャレンジは `challengeWindow`、ブロックは `blockWindow`、プライドの喪失とトリガーは `loseInfluence` / `resolveTrigger`。
- CPU：`cpuChooseAction` ほか `cpu*` 関数。
- チュートリアル：`tutSetup` の `TUT.beats`（ナビの台詞と許可する選択）と `TUT.cpu`（CPUの台本）。
- 印刷データ：`tools/print_cards.py`。`python3 -I tools/print_cards.py --out <dir> --art <元立ち絵dir> --size 91x55 --bleed 1.5 --lion` で物理版52枚（ガキ15・メスガキ12＝モモコ・グリムアロエ・アクア・パイン・シロ・クロ・トリガー18・早見表6・タイトル1）の表裏 PNG と1面1ページの PDF を出す。`--lion` でライオン名刺「異種」21面テンプレート用に回転済みの面画像と参考面付けも出す。文言と枚数は `index.html` の定義から読む。
- 分析ページ：`docs/trigger-analysis.html`。`tools/summarize.py basic_p4=a.json basic_p3456=b.json fresh_p4=c.json fresh_p3456=d.json docs/sim_summary.json` でまとめ、`tools/build_analysis.py docs/sim_summary.json <artifact.html> docs/trigger-analysis.html` でページを生成する。
- バランス検証：`tools/sim.js`（Playwright）。`node tools/sim.js 10000 4 0 deck=fresh` で「1万戦・4人戦・ハズレなし・新カードデッキ」をヘッドレスで回し、トリガーごとの勝率をJSONで出す。ゲーム側は `S.headless=true` で描画・待ち・演出・音を飛ばす。

立ち絵はボンバーガールのキャラクター画像を使った私的なファン用です。画像の権利は各権利者にあります。

# メスガキに「は？」って言うゲーム ～メスガキ・クー～

カードゲーム「クー (Coup)」にメスガキ要素を足したブラウザゲームです。
基本ルールはクーのまま。コインは♥、役職はガキカード、ライフを失うとキャラカードが裏返ってボロ絵になり、その下に敷いたトリガーカードが発動します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールは要りません。

- 初めてなら開始画面の「チュートリアル」を。台本どおりに進む1戦を遊びながら、ナビが毎手の意味（主張・ブロック・ダウト・脱ぐ・トリガー・ばいば～い♥）を説明し、押す場所を絞って案内します。
- 対戦人数はクーと同じ3〜6人（あなた＋CPU）。
- トリガーは開始画面で「基本デッキ」「新カードデッキ」「おすすめデッキ」か、全カードから好きな18枚を選ぶ「カスタム」を選べます（選択は保存されます）。「おまかせ」にすると自分の手もCPUに任せて観戦できます。
- 画面上の「ルール」ボタンで早見表（アクション・ガキカード・トリガー）が見られます。
- 自分の番は、アクションのタイル（ガキカードと同じ色・同じ名前の帯）を押すか、手札のカードを直接クリックして行動します。持っていない役職のタイルは破線で「ハッタリ」と表示されます。ほかのプレイヤーの主張には「ダウト！」や「は？」ブロックで割り込めます。

### アクション

| アクション | 条件 | 効果 | 「は？」ブロック | ダウト |
| --- | --- | --- | --- | --- |
| ざこ♥ | なし | 1♥獲得 | 不可 | 不可 |
| ざこざこ♥ | なし | 2♥獲得 | メスガキ | 不可 |
| ばいば～い♥ | 7♥（10♥以上なら必須） | 相手のプライドを1つ失わせる | 不可 | 不可 |
| ざぁ～こ♥ | メスガキ | 3♥獲得 | 不可 | 可 |
| なさけな～い♥ | 後輩ガキ | 相手から2♥奪う | 後輩ガキ・幼馴染ガキ | 可 |
| ふ～ん♥ | 幼馴染ガキ | 山札から2枚引き、2枚捨てる | 不可 | 可 |
| まけちゃえ～♥ | サキュガキ＋3♥ | 相手のプライドを1つ失わせる | わからせおじさん | 可 |

### プライドを失ったとき

1. 手札（ガキカード）を1枚、自分で選んで捨てる。
2. 失わせた相手が、キャラカードの上か下を選んで裏返し、ボロ絵にする。
3. その横に敷いていたトリガーカードを表にして効果を発動する（自分のトリガーは自分だけ見える）。

両方ボロ絵になったら脱落。最後の1人が勝ち。

## この実装での取り決め

早見表に書かれていない部分は `index.html` 冒頭の `RULES` で切り替えられます。

- `peekOwnTriggers`：自分のトリガーを自分だけ見られる（既定 ON）。
- `triggerDeal`：開始時に配るトリガー枚数（既定 3。3枚から2枚を選んで上半身・下半身に仕込み、残り1枚は山に戻す）。2にすると配られた2枚をそのまま仕込む。
- デッキのプリセットは `DECK_PRESETS`（basic / fresh / mix）。ゲームに使う18枚は `DECK.ids`（3〜6人に3枚ずつ配れる枚数）。カードの系統（札の「基本／新カード／2軍」表記）は `SETS`。
- `collectorGoal`：メンヘラの勝利条件（既定 9♥。持っていれば9♥になった時点で勝ち）。公開した瞬間に山分け（自分より♥の多い全員から1♥）も起きる。
- `punishCost`：わからせ返しの即時ばいば～い♥のコスト（既定 5♥）。
- `attackerChoosesFlip`：プライドを失わせた側が、相手の上半身・下半身どちらを脱がせるか選ぶ（既定 ON）。
- `dudCount`：ハズレ（効果なし）トリガーの枚数（既定 0）。
- こっそり見せてで見た相手の手札、いいから見せてで見た相手のトリガーは、見た本人にだけ表示される（CPUも覚えて判断に使う。知っているトリガーがあれば、脱がせるときに自分へ跳ね返りにくい方を選ぶ）。
- おきがえしま～す！（2軍）はプライドが0になる脱ぎでめくれたときだけ発動する。山札から1枚引いて脱落を免れる（♥は0になる）。服は両方ボロのまま続行し、次にプライドを失うと脱落。
- 全員が同時に脱落したら（わからせ返しの相打ちなど）、最後に脱落した人の勝ち。
- `win15LiftsForcedCoup`：「メンヘラ」を持つ人は10♥の強制ばいば～い♥を免除（既定 ON。`collectorGoal` を10♥より上にしたときに効く）。
- テレパシーは持ち主だけに効く。以後その人の「ふ～ん♥」は、通常（山札から2枚引いて2枚戻す）かみせて♥（相手の手札1枚を見て山札と交換させる。幼馴染ガキでブロック可）かを宣言時に選べる。
- あんたもみちづれ！は、脱がせてきた相手の手札が2枚のときだけ発動する（1枚の相手には不発）。
- ぜんぶちょーだいは全員（自分も）が手札を1枚伏せて出し、持ち主だけが全部見て1枚もらう。残りはシャッフルして自分以外に1枚ずつ戻す。
- 公開・交換で手放したガキカードは捨て札に置く。山札が尽きたら捨て札を切り直して山札にする（失ったプライドのカードは戻らない）。
- 「見せないが？」は公開済みトリガーによるブロックなので、ダウトできない。
- 「魔除け」も公開済みトリガーによるブロック（まけちゃえ～♥を止める。撃った側の3♥は戻らない）。「見せないが？」は「見せて」が名前に入るトリガー（こっそり見せて・み～んな見せて・いいから見せて）の効果も、持ち主には効かなくする。
- み～んな見せては「2♥渡す」か「手札1枚を見せる」か。まるみえは自分以外の全員の手札を表にする。
- カード名・アクション名・用語は用語集（Claude Docs「メスガキ・クー ルール用語表」）の決定どおり。`TRIGGERS` / `ACTIONS` を書き換えれば変更できます。
- わからせおじさんのブロック台詞も空欄だったので「は？負けさせないが？」を仮置きしています。

## 構成

ゲームは `index.html` 一枚です。

- 役職・アクション・トリガー・台詞：`ROLES` / `ACTIONS` / `TRIGGERS`
- キャラ（id と表示名）：`CHARS`
- 立ち絵：`img/{id}_{top|bottom}_{000|001}.webp`（000=通常絵、001=ボロ絵）を上半身・下半身の2枚のカードとして表示します。画像が無いときはキャラ名のプレースホルダーになります。
- 画像の生成：`tools/split_cards.py` が元の立ち絵（通常絵の透過PNGとボロ絵のJPG）を腰の位置で上下に分割し、印刷用PNGとA4両面シートを出力します。ゲーム用の `img/` はその出力を 416×298 の WebP に縮小したものです。
- 進行：`runGame` → `takeTurn` → `performAction`。ダウトは `challengeWindow`、ブロックは `blockWindow`、プライドの喪失とトリガーは `loseInfluence` / `resolveTrigger`。
- CPU：`cpuChooseAction` ほか `cpu*` 関数。
- チュートリアル：`tutSetup` の `TUT.beats`（ナビの台詞と許可する選択）と `TUT.cpu`（CPUの台本）。
- 印刷データ：`tools/print_cards.py`。`python3 -I tools/print_cards.py --out <dir> --art <元立ち絵dir> --size 91x55 --bleed 1.5 --lion` で物理版52枚（ガキ15・キャラ12＝モモコ・グリムアロエ・アクア・パイン・シロ・クロ・トリガー18・早見表6・タイトル1）の表裏 PNG と1面1ページの PDF を出す。`--lion` でライオン名刺「異種」21面テンプレート用に回転済みの面画像と参考面付けも出す。 `--template <異種テンプレート.ai>` を足すと、テンプレートの表・裏ページに各面を貼り込んだ入稿データを `.pdf` と `.ai`（同じ内容のPDF互換ファイル。テンプレート由来の Illustrator 編集データは外してある）で出す。`--all-triggers --chars all --dud 2 --ref 8 --blank 20` で100枚セット（ガキ15・メスガキ20・トリガー40・ハズレ2・早見表8・白紙トリガー14・タイトル1）。文言と枚数は `index.html` の定義から読む。
- 分析ページ：`docs/trigger-analysis.html`。`tools/summarize.py basic_p4=a.json basic_p3456=b.json fresh_p4=c.json fresh_p3456=d.json docs/sim_summary.json` でまとめ、`tools/build_analysis.py docs/sim_summary.json <artifact.html> docs/trigger-analysis.html` でページを生成する。
- バランス検証：`tools/sim.js`（Playwright）。`node tools/sim.js 10000 4 0 deck=fresh` で「1万戦・4人戦・ハズレなし・新カードデッキ」をヘッドレスで回し、トリガーごとの勝率をJSONで出す。ゲーム側は `S.headless=true` で描画・待ち・演出・音を飛ばす。

立ち絵はボンバーガールのキャラクター画像を使った私的なファン用です。画像の権利は各権利者にあります。
